Technique

Why this works

01 / Ring

A circular element uses four different border colors to create the segmented outer ring.

02 / Cutout

A pseudo-element masks part of the right side using the current canvas color.

03 / Crossbar

A second pseudo-element draws the horizontal blue bar that completes the G-like silhouette.

04 / Constraints

The control model clamps size and stroke so the construction stays geometrically valid.
